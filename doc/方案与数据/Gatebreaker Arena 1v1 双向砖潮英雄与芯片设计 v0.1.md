# Gatebreaker Arena 1v1 双向砖潮英雄与芯片设计 v0.1

> **状态**：新 1v1 模式的扩展设计草案，基础玩法验证通过后再进入实现。  
> **关联玩法**：[Gatebreaker Arena 1v1 双向砖潮对战设计 v0.1](Gatebreaker%20Arena%201v1%20双向砖潮对战设计%20v0.1.md)  
> **隔离原则**：本文不修改现有守门弹球模式的英雄系统 v0.5、芯片清单 v0.1 或其数据 ID。新模式使用独立规则、独立效果和独立 ID。

## 0. 调整结论

现有英雄和芯片不能直接搬入双向砖潮 1v1，原因如下：

1. 双方弹球只在各自半场活动，不再发生“敌球碰我方挡板”或球权交换。
2. 新模式没有球门得分、主动发球、弹药库存和发球冷却。
3. 常态严格保持每方一颗弹球，不使用多球爆发。
4. 弹球速度是全局固定基础参数，不随阶段或常规构筑直接变化。
5. 砖块紧密排列并以统一速度移动；单颗砖不能被独立减速、击退或停止。
6. 胜负来自清砖效率、路线规划与核心生命管理，不允许英雄直接扣除对手生命。

因此，新模式的英雄与芯片应围绕四个新支点设计：

- **清砖方式**：单点、高耐久、贯穿、邻接破坏。
- **弹道控制**：挡板落点、角度、墙面反弹、失球复位。
- **砖潮管理**：全局暂停、统一减速、危险行预警；任何速度修改必须同步影响补行速度。
- **核心防护**：抵消漏砖伤害、失血后的短时恢复窗口，但不直接治疗或永久增加生命上限。

## 1. 上线分层

### 1.1 V0：基础玩法验证

V0 不启用英雄和芯片，只验证：

- 每方一球是否足以形成持续操作；
- 紧密砖潮是否始终可读；
- 统一推进与连续补行是否能制造合理压力；
- 90 秒内是否能稳定出现 1～3 次掉血；
- 挡板落点是否真正影响清砖效率。

V0 未通过前，不应通过英雄技能修补基础节奏。

### 1.2 V1：英雄身份验证

V1 只加入 3 名英雄，每名保留 2 条路线。英雄负责改变玩家的“清砖方法”，不增加基础球数，不修改对手操作，不直接伤害对手核心。

### 1.3 V1.1：芯片构筑验证

英雄路线稳定后，再加入少量通用芯片。首轮不沿用旧模式的 6 芯片和 M1/M2/M3 系统，避免 90 秒内规则叠加过快。

建议首轮配置：

```text
1 名英雄
+ 1 条主路线
+ 1 张路线专属芯片
+ 3 张通用芯片
= 全部从开局生效
```

## 2. 英雄调整

### 2.1 「霜降」：从控制对手改为管理本方砖潮

#### 核心资源

“寒意”由本方弹球击碎砖块积累。不同砖块可提供不同寒意，但同一次连锁有获取上限，防止大面积清除后无限循环。

#### 极寒之路：冻结砖潮

核心循环：

```text
清砖积累寒意
→ 寒意满值
→ 冻结本方全部砖块
→ 获得短暂整理弹道与救近线砖的窗口
```

建议基础效果：

- 寒意达到 8 点后可释放；
- 本方全部砖块停止推进 1.5 秒；
- 冻结期间推进速度视为 0，因此空间线同步停止补行；
- 冻结结束后恢复原统一推进速度，不产生速度补偿或瞬移；
- 不冻结对方挡板、弹球或砖潮。

路线体验是“争取时间”，适合防守和局面整理。

#### 冰晶之路：脆化砖块

核心循环：

```text
清砖积累寒意
→ 寒意满值
→ 本方弹球进入冰晶状态
→ 提高清除坚固砖的效率
```

建议基础效果：

- 寒意达到 6 点后，下一次挡板反弹令弹球进入冰晶状态；
- 接下来 3 次砖块命中额外造成 1 点伤害；
- 不提高弹球速度，不复制弹球；
- 对普通砖不会产生溢出范围伤害，主要用于处理坚固砖和重压砖。

路线体验是“处理高耐久目标”，适合主动规划弹道。

#### 与旧版霜降的关系

保留低温积累、冻结和冰晶转化的主题；删除以下旧规则：

- 敌球碰挡板积累低温；
- 冻结或减速对方挡板；
- 低温附着于跨场球权；
- 低温转化为球速增益。

### 2.2 「工事」：从封锁敌球改为保护核心与引导本方弹道

#### 核心资源

“工事充能”随时间恢复，也可由成功用挡板接球少量加速恢复。工事实体只能影响本方弹球或核心结算，不能阻挡砖潮并造成局部砖块脱离统一速度。

#### 堡垒之路：核心护壁

核心循环：

```text
维持接球
→ 恢复护壁
→ 漏砖到达核心线
→ 护壁抵消一次伤害
```

建议基础效果：

- 每 25 秒获得 1 层护壁，最多 1 层；
- 砖块触底时先消耗护壁，使本次核心伤害减少 1；
- 砖块仍正常消失，护壁不在场内阻挡或挤压砖阵；
- 重压砖造成 2 点伤害时，护壁仅抵消其中 1 点；
- 护壁不回复已经失去的生命。

路线体验是“提高失误容限”，但不能无限拖延。

#### 炮台之路：导向反射器

核心循环：

```text
连续接球积累部署
→ 在本方半场放置短时反射器
→ 改写一次弹球路线
→ 命中目标列或近线砖
```

建议基础效果：

- 连续完成 5 次挡板反弹后获得一次部署；
- 玩家在本方半场选择一个位置和倾角，生成持续 4 秒的短反射器；
- 反射器只与本方弹球碰撞，不影响砖块；
- 同时最多存在 1 个，使用后重新积累；
- 反射器不自动追踪砖块，不保证命中，保留玩家的路线判断。

路线体验是“重构弹道”，继续保留工事英雄的空间几何身份。

#### 与旧版工事的关系

保留屏障、建造和反弹导向主题；删除以下旧规则：

- 根据敌球密度部署屏障；
- 将敌球导向敌门；
- 发射减速对手挡板的电弧；
- 屏障承受多球压力或清除球上低温。

### 2.3 「蓄能」：从多球与球速爆发改为清砖爆发

#### 核心资源

“能量”由连续击碎砖块获得。弹球连续一段时间没有击碎砖块时，连击中断，但已经储存的能量不立即清零。

#### 充能之路：贯穿兑现

核心循环：

```text
连续清砖储存能量
→ 主动选择兑现时机
→ 下一次挡板反弹获得贯穿
→ 打开一条救场通道
```

建议基础效果：

- 储满 6 层能量后可释放；
- 下一次挡板反弹后，弹球获得 3 次贯穿；
- 贯穿命中砖块时正常造成伤害，但弹球不反弹；
- 每穿过一块砖消耗 1 次；
- 不生成复制球，不提高弹球速度。

路线体验是“储存后一次性打开通路”。

#### 光芒之路：连续扩散

核心循环：

```text
持续清砖维持连击
→ 周期性释放小范围光波
→ 伤害相邻砖块
→ 继续维持清除节奏
```

建议基础效果：

- 每连续击碎 4 块砖，触发一次光波；
- 光波对被击碎砖块左右相邻的砖各造成 1 点伤害；
- 每次球飞行周期最多触发 1 次，回到挡板后刷新；
- 连击中断时计数清零；
- 不提高球速，不扩大为全屏清除。

路线体验是“持续经营并获得稳定扩散收益”。

#### 与旧版蓄能的关系

保留积累、兑现和持续经营主题；删除以下旧规则：

- 临时分裂为 2～3 颗球；
- 爆发球速提高；
- 依赖进球结算的护盾；
- 多球对屏障的承压克制。

## 3. 新模式通用芯片

旧模式的 `STRIKE_*`、`GUARD_*`、`FLOW_*` ID 不改变。新模式使用 `DUEL_*` 前缀，避免同名芯片在两套规则中产生不同语义。

### 3.1 破阵类（Break）

| Chip ID | 名称 | 建议效果 | 取舍 |
|---|---|---|---|
| `DUEL_BREAK_HEAVY` | 重击 | 每次挡板反弹后的首次砖块命中额外造成 1 点伤害。 | 只强化首次命中，不提高连续清普通砖效率。 |
| `DUEL_BREAK_ANGLE` | 折射瞄准 | 挡板边缘反弹的最大偏转角增加 10°。 | 中央稳定区缩小 10%。 |
| `DUEL_BREAK_CHAIN` | 连锁震荡 | 连续击碎 5 块砖后，对一块横向相邻砖造成 1 点伤害。 | 每次球飞行周期最多触发 1 次。 |
| `DUEL_BREAK_PIERCE` | 穿芯 | 每第 6 次砖块命中获得 1 次贯穿。 | 挡板长度减少 8%。 |

### 3.2 守核类（Guard）

| Chip ID | 名称 | 建议效果 | 取舍 |
|---|---|---|---|
| `DUEL_GUARD_LENGTH` | 长板 | 挡板长度增加 15%。 | 挡板移动速度降低 8%。 |
| `DUEL_GUARD_CORE` | 应急装甲 | 每局首次漏砖伤害减少 1。 | 只触发一次，不能恢复生命。 |
| `DUEL_GUARD_WARNING` | 危险扫描 | 最前排进入危险区时提前显示预计触底位置。 | 只提供信息，不改变数值。 |
| `DUEL_GUARD_RECOVERY` | 紧急缓冲 | 受到核心伤害后，本方砖潮统一推进速度降低 20%，持续 2 秒。 | 同步降低补行速度；每 20 秒最多触发一次。 |

### 3.3 操球类（Control）

| Chip ID | 名称 | 建议效果 | 取舍 |
|---|---|---|---|
| `DUEL_CONTROL_PADDLE` | 疾行 | 挡板移动速度增加 15%。 | 挡板长度减少 5%。 |
| `DUEL_CONTROL_CENTER` | 稳定击球 | 扩大挡板中央的稳定反弹区。 | 边缘最大偏转角降低 8°。 |
| `DUEL_CONTROL_WALL` | 墙面校准 | 弹球碰侧墙后，修正过度水平的轨迹，保证最低纵向分量。 | 不提供伤害或速度增益。 |
| `DUEL_CONTROL_RESET` | 快速回收 | 弹球卡死或离场后的重置时间减少 50%。 | 重置球不携带英雄状态、贯穿或连击。 |

## 4. 路线专属芯片

每条路线首轮只设计两个侧向变体：稳定型和兑现型。变体只调整本路线已有资源与结果，不新增第二套机制。

| 英雄路线 | 稳定型方向 | 兑现型方向 |
|---|---|---|
| 霜降·极寒 | 寒意获取更稳定，冻结时长略短。 | 冻结时长更长，寒意门槛更高。 |
| 霜降·冰晶 | 冰晶命中次数增加，额外伤害不变。 | 额外伤害提高，但命中次数减少。 |
| 工事·堡垒 | 护壁恢复更快，但只能抵消普通砖伤害。 | 可抵消重压砖 2 点伤害，但整局只触发一次。 |
| 工事·炮台 | 反射器持续更久、尺寸更大。 | 反射角更自由，但持续更短。 |
| 蓄能·充能 | 储能门槛降低，贯穿次数减少。 | 贯穿次数增加，储能门槛提高。 |
| 蓄能·光芒 | 连击中断宽限时间增加。 | 光波可纵向扩散一次，但触发门槛提高。 |

建议使用新 ID：

```text
DUEL_SIG_FROST_FREEZE_*
DUEL_SIG_FROST_CRYSTAL_*
DUEL_SIG_MECH_FORTRESS_*
DUEL_SIG_MECH_REFLECTOR_*
DUEL_SIG_RADIANT_PIERCE_*
DUEL_SIG_RADIANT_GLOW_*
```

## 5. 旧芯片迁移判断

| 旧机制 | 新模式处理 |
|---|---|
| 发球初速、速射、弹药冷却、弹药上限 | 删除；新模式没有主动发球与弹药。 |
| 球门缩小、敌球减速、敌球飞向球门时制动 | 删除；新模式没有敌球进入本方半场或球门判定。 |
| 挡板长度、挡板移速、反弹角度 | 可保留设计意图，但使用新 ID 和重新平衡后的数值。 |
| 球速提高、球速上限提高 | 首轮禁用；弹球速度保持固定。 |
| 分裂、多球、复制球 | 首轮禁用；每方常态一球是基础可读性约束。 |
| 屏障、护盾 | 可转化为本方弹道反射器或核心伤害抵消，不得阻挡局部砖块移动。 |
| 冻结、减速 | 只能作用于本方整片砖潮，并同步影响新行生成速度；不作用于单砖或对方挡板。 |

## 6. PvP 互动边界

双向砖潮首轮允许双方“看见对方状态”，但不允许英雄直接干扰对方操作。以下效果暂不进入 V1：

- 冻结、减速或缩短对方挡板；
- 向对方场地直接添加额外砖块；
- 提高对方砖潮速度；
- 直接扣除对方核心生命；
- 操纵、删除或复制对方弹球；
- 隐藏对方砖块、轨迹或 HUD；
- 随机交换双方砖阵。

这样做的原因是：基础模式本身已经通过生命差形成竞速压力。如果同时加入控制、垃圾行和多球，失败原因会重新变得不可读。

如果后续测试证明“双方像并排玩单机”，应新增一套全英雄共享、双方都能预期的公共互动规则，而不是让少数英雄独占直接攻击。例如可单独验证：

- 清除特定中央砖后，下一次双方同时生成一行特殊砖；
- 双方争夺同一个可见的阶段增益；
- 领先方与落后方都能通过明确条件触发对称风险。

这些内容必须独立立项，不与首轮英雄重做捆绑。

## 7. 平衡红线

- 每方常态最多 1 颗弹球。
- 常规芯片和英雄路线不直接修改弹球速度。
- 任意砖潮减速、暂停或加速都作用于本方全部砖块，并同步影响补行速度。
- 单次英雄效果不能清除整屏砖块。
- 核心护盾只能减伤，不能恢复生命或提高最大生命。
- 自动瞄准只能提供提示或有限角度修正，不能替代挡板落点操作。
- 稳定型和兑现型专属芯片必须有清晰取舍，不做纯数值上下位。
- 对局中的英雄资源、就绪状态和持续时间必须让双方可见。

## 8. 首轮验收指标

1. 玩家能否在一局内说清自己英雄改变了哪一种清砖方法。
2. 使用不同英雄时，最优弹道选择是否明显不同。
3. 英雄效果是否帮助处理危险砖，而不是掩盖基础操作失误。
4. 失败者能否判断自己是弹道规划、挡板操作还是技能时机出了问题。
5. 三名英雄对普通砖、坚固砖和重压砖是否各有强项，但不存在必选角色。
6. 芯片组合是否产生侧向选择，而不是简单堆叠伤害、挡板长度或容错。
7. 开启英雄与芯片后，场面中仍是否始终只有两颗可追踪弹球。

## 9. 推荐实施顺序

```text
双向砖潮 V0
→ 固定英雄基础被动
→ 每名英雄只实现 1 条路线
→ 三英雄互测
→ 补齐每名英雄第 2 条路线
→ 加入 12 张通用芯片
→ 加入路线专属侧向变体
→ 最后再评估公共 PvP 互动规则
```

首个英雄实现建议选择「蓄能·充能」。贯穿只改变本方弹球与砖块碰撞，依赖最少、反馈直接，最适合验证“英雄是否能提升清砖决策，而不破坏双向砖潮的可读性”。
