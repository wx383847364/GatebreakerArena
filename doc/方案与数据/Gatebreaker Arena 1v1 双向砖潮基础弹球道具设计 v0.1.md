# Gatebreaker Arena 1v1 双向砖潮基础弹球道具设计 v0.1

> **状态**：基础玩法验证通过后的道具扩展草案。  
> **依赖规则**：[Gatebreaker Arena 1v1 双向砖潮无尽对战规则 v0.1](Gatebreaker%20Arena%201v1%20双向砖潮无尽对战规则%20v0.1.md)  
> **适用模式**：仅适用于 1v1 双向砖潮无尽对战，不复用现有守门弹球模式的道具数据。  
> **实现边界**：基础规则 V0 仍不掉落道具；本文用于 V0 验证通过后的首个道具版本。

## 0. 设计结论

首个道具版本采用“击碎 `？` 砖 → 掉落道具舱 → 本方挡板接取 → 立即生效”的单人半场循环。

道具只帮助玩家处理自己的弹球、挡板、砖潮和核心风险，不直接干扰对手。首发池包含 6 种效果：

| Item ID | 名称 | 类型 | 一句话效果 |
|---|---|---|---|
| `DUEL_ITEM_WIDE_PADDLE` | 宽幅组件 | 挡板 | 挡板短时变宽。 |
| `DUEL_ITEM_LARGE_BALL` | 扩容球体 | 弹球 | 弹球短时变大，球速和单次伤害不变。 |
| `DUEL_ITEM_PHASE_DRILL` | 相位钻头 | 弹球 | 接下来数次命中仍只造成 1 点伤害，但弹球不反弹。 |
| `DUEL_ITEM_SPLIT_BALL` | 裂变球体 | 弹球 | 己方每个球各分裂出 1 颗有限撞砖次数的新球；源球不变。 |
| `DUEL_ITEM_DAMPING_PULSE` | 阻尼脉冲 | 砖潮 | 本方整片砖潮短时减速，补砖同步减慢。 |
| `DUEL_ITEM_CORE_BUFFER` | 核心缓冲 | 核心 | 限时抵消下一次 1 点漏砖伤害。 |

首发池不包含无限多球、球速变化、生命恢复、直接攻击、随机传送、全屏清除或对手控制。裂变球体是唯一允许的临时多球例外，且每颗分裂球必须以砖块命中次数作为寿命上限。

## 1. 设计目标

### 1.1 体验目标

- **一眼能懂**：玩家看到图标和颜色后，能在一次拾取内理解效果。
- **服务基础操作**：道具强化接球、弹道规划和危险砖处理，不替代这些操作。
- **制造短时决策**：玩家需要判断是否为了接道具舱调整挡板位置，以及何时利用短时效果改变弹道。
- **失败原因清楚**：道具失效、漏接或使用窗口结束都必须有明确反馈。
- **无尽局可控**：效果有持续时间或次数上限，不随对局时间永久累积。

### 1.2 规则目标

- 常态始终保持每方 1 颗母球；允许存在有限寿命的分裂球，但不能替代母球。
- 不修改固定基础球速 `V_ball_base`。
- 不修改全局基础砖潮速度 `V0`；临时砖潮效果必须同时影响移动与补砖。
- 不恢复已经失去的核心生命，也不提高生命上限。
- 不改变双方共用的镜像逻辑行和砖型数据。
- 所有掉落类型、拾取与效果结算均可由权威状态确定性回放。

## 2. 道具产生与接取

### 2.1 产生条件

1. 弹球击碎本方半场内的 `？` 砖。
2. `？` 砖按普通规则消失，并在其中心生成 1 个道具舱。
3. 道具舱只属于该半场，不会跨越中央空间线，也不能被对方接取。
4. `？` 砖抵达核心线时只造成原规则规定的 1 点伤害，不生成道具舱。
5. 由范围效果或连锁效果击碎 `？` 砖时同样掉落；同一砖始终最多掉落 1 次。
6. 母球与分裂球击碎 `？` 砖均可掉落；掉落归属仍是该半场。

首发版本中，每个被击碎的 `？` 砖必定掉落 1 个道具舱。随机性已经由 `？` 砖的 5% 生成占比控制，不再增加第二层“是否掉落”判定。

### 2.2 道具类型确定

道具类型不能在砖块被击碎时临时随机。每个 `？` 砖写入逻辑行记录时，必须同时写入不可变的 `item_id`：

```text
item_id = DeterministicItem(match_seed, row_id, column_id, composition_stage)
```

逻辑行记录扩展为：

```text
row_id
composition_stage
brick_types_by_column[]
item_ids_by_column[]        // 非“？”砖位置写 null
random_sequence_position
```

上下双方镜像位置的 `？` 砖使用相同 `item_id`。双方能否击碎并接到道具由各自操作决定，但潜在奖励必须一致。

首轮 6 种道具使用等权重池：

| 道具 | 权重 |
|---|---:|
| 宽幅组件 | 1/6 |
| 扩容球体 | 1/6 |
| 相位钻头 | 1/6 |
| 裂变球体 | 1/6 |
| 阻尼脉冲 | 1/6 |
| 核心缓冲 | 1/6 |

建议仍使用确定性洗牌袋，而不是逐次独立抽取。每 12 个 `？` 砖组成一袋，每种道具 2 个；配比阶段切换不清空道具袋，避免时间边界改变已确定的奖励序列。

### 2.3 掉落运动

- 道具舱从被击碎位置沿砖潮推进方向落向本方核心线。
- 道具舱不与弹球、砖块、墙体和其他道具舱发生实体碰撞。
- 道具舱与本方挡板重叠时判定接取并立即消失。
- 道具舱越过核心线时判定漏接并消失，不造成核心伤害。
- 道具舱不会被核心缓冲抵挡，也不会阻挡砖块或弹球。
- 道具舱建议速度为 `V_item_drop = 0.65 × V_ball_base`，最终值需结合半场高度验证。
- 同一半场同时最多存在 2 个未接取道具舱；生成第 3 个时，最早生成的道具舱立即失效。

接取判定使用固定模拟帧。若同一帧发生“道具舱碰挡板”和“道具舱越过核心线”，先结算接取，再结算越界。

## 3. 首发道具详细规则

### 3.1 宽幅组件

| 项目 | 规则 |
|---|---|
| Item ID | `DUEL_ITEM_WIDE_PADDLE` |
| 效果 | 本方挡板宽度变为基础宽度的 `125%`。 |
| 持续时间 | 8 秒。 |
| 重复接取 | 不叠加宽度；持续时间重置为 8 秒。 |
| 结束处理 | 以挡板中心为锚点恢复基础宽度，并限制在场地横向边界内。 |

设计用途：降低短时间内的接球压力，让玩家有余力调整下一次反弹角度。它提高容错，但不会自动清砖。

### 3.2 扩容球体

| 项目 | 规则 |
|---|---|
| Item ID | `DUEL_ITEM_LARGE_BALL` |
| 效果 | 本方**母球**碰撞半径变为基础半径的 `115%`。 |
| 持续时间 | 8 秒。 |
| 不变项 | 球速、质量表现、单次砖块伤害和母球场上数量不变。 |
| 作用范围 | 只作用于母球；已存在或后续生成的分裂球不继承该半径。 |
| 重复接取 | 不叠加半径；持续时间重置为 8 秒。 |
| 结束处理 | 在安全位置恢复半径；若与墙体或砖块重叠，先沿最近可分离方向推出，再继续模拟。 |

设计用途：稍微提高穿过紧密砖缝时的命中覆盖，但不提供额外伤害。实现前必须通过连续碰撞测试，避免一次接触重复扣除同一砖块生命。

### 3.3 相位钻头

| 项目 | 规则 |
|---|---|
| Item ID | `DUEL_ITEM_PHASE_DRILL` |
| 效果 | 本方**母球**接下来 3 次有效砖块命中不改变弹球方向。 |
| 消耗 | 每命中 1 块砖消耗 1 次；对砖仍只造成 1 点伤害。 |
| 持续时间 | 最长保留 10 秒；次数耗尽或超时后结束。 |
| 作用范围 | 只作用于母球；分裂球不获得贯穿能力。 |
| 重复接取 | 剩余次数增加 3，最多保留 5 次；持续时间重置为 10 秒。 |
| 特殊碰撞 | 同一固定模拟帧按飞行方向依次结算接触砖；每块砖最多消耗 1 次。 |

相位钻头只取消本次砖块碰撞对弹球方向的影响，不会直接消灭耐久砖：

```text
命中黄色砖（生命 3）→ 扣除 1 点生命并变为红色砖（生命 2）→ 弹球继续前进
命中红色砖（生命 2）→ 扣除 1 点生命并变为绿色砖（生命 1）→ 弹球继续前进
命中绿色砖（生命 1）→ 扣除 1 点生命并消失                 → 弹球继续前进
```

弹球进入一块砖的碰撞体后，必须先完全离开该碰撞体，才能再次对同一块砖造成伤害。持续重叠、连续碰撞检测或同一固定模拟帧内的重复接触均不得重复扣血或重复消耗贯穿次数。

设计用途：让玩家通过挡板落点主动打开一条通路，尤其适合处理纵向排列的耐久砖。它不提高单次伤害，不会把耐久砖直接秒杀，也不会一次穿透无限砖块。

### 3.4 裂变球体

| 项目 | 规则 |
|---|---|
| Item ID | `DUEL_ITEM_SPLIT_BALL` |
| 效果 | 对本方半场**当前每一颗仍在场的球**（含母球与已有分裂球）各生成 1 颗新分裂球；**所有源球的位置、速度、半径与剩余状态保持不变**。 |
| 分裂球数量 | 若接取时己方有 `N` 颗球，则本帧新增 `N` 颗分裂球；**不设同半场分裂球数量上限**。 |
| 碰撞上限 | 每颗**新生成**的分裂球拥有独立的 `remaining_brick_hits = 3`。 |
| 消耗规则 | 分裂球每命中 1 块砖，消耗 1 次；次数归零后立即消失。 |
| 有效消耗 | 仅计入砖块命中；对砖仍只造成 1 点伤害。 |
| 不计入 | 挡板反弹、左右边界、核心线外侧边界、中央空间线、与道具舱/其他弹球重叠、系统分离修正。 |
| 球速与半径 | 新分裂球使用基础球速 `V_ball_base` 与基础半径；不继承源球的扩容、贯穿等状态。 |
| 初始方向 | 以对应源球当前速度方向为基准偏转 `+30°`；若同帧有多颗源球，各自独立计算。速度模长仍等于 `V_ball_base`。 |
| 初始位置 | 沿各自初始方向相对**对应源球**中心外推 `源球半径 + 新球半径 + 0.02`，避免生成即重叠。 |
| 重复接取 | 再次对当时场上每一颗球各分裂出 1 颗新球；不改写、不清除、不重置已有分裂球的剩余撞砖次数。 |
| 母球关系 | 母球失球重置、卡住重置、相位/扩容状态变化，均不自动清除或改写分裂球。 |
| 结束处理 | 分裂球砖块命中次数耗尽、越过核心线失球、或对局进入 `Result` 时移除；不造成额外核心伤害。 |

分裂球与母球共用同一半场碰撞规则，但仍只属于生成方半场，不能穿越中央空间线。挡板与边界反弹照常进行，且不消耗次数。

```text
接取裂变球体时己方有 N 颗球
→ 快照当前场上全部源球（母球 + 已有分裂球）
→ 对每个源球 S：
    保持 S 原样不变
    生成新分裂球：方向 = S.方向 + 30°，remaining_brick_hits = 3
→ 本帧新增 N 颗分裂球
→ 任意分裂球命中砖块 1 次 → remaining_brick_hits -= 1
→ remaining_brick_hits 归零 → 该分裂球立即消失
```

示例：

```text
仅有母球（N=1）→ 新增 1 颗分裂球，场上共 2 颗
母球 + 1 分裂球（N=2）→ 再新增 2 颗，场上共 4 颗
母球 + 3 分裂球（N=4）→ 再新增 4 颗，场上共 8 颗
```

设计用途：提供可叠加的短窗口清砖覆盖，但不把局面改造成无限寿命多球。母球始终是可追踪的主球；分裂球是会因撞砖次数耗尽而消失的辅助弹道。

验收重点：

1. 接取后所有源球（含母球与旧分裂球）的速度向量、半径与剩余撞砖次数完全不变。
2. 每次接取新增数量等于接取瞬间己方在场球数；同半场不设数量上限。
3. 仅新生成的分裂球带满 3 次砖块命中；撞挡板与边界不耗次数。
4. 新分裂球不会继承相位钻头或扩容球体。
5. 分裂球击碎 `？` 砖时仍按权威 `item_id` 掉落，不额外随机。

### 3.5 阻尼脉冲

| 项目 | 规则 |
|---|---|
| Item ID | `DUEL_ITEM_DAMPING_PULSE` |
| 效果 | 本方所有砖列实际推进速度乘以 `70%`。 |
| 持续时间 | 4 秒。 |
| 补砖 | 每列补砖间隔按减速后的实际速度同步变化。 |
| 重复接取 | 不叠加减速幅度；持续时间重置为 4 秒。 |
| 结束处理 | 各列从当前位置恢复原实际速度，不追赶、不瞬移、不补偿减速期间的距离。 |

效果期间第 `c` 列使用：

```text
V_c(t) = V0 × S_c(t) × 0.70
T_c(t) = H ÷ V_c(t)
```

设计用途：提供短暂整理窗口。它只改变拾取方当前局势，不修改逻辑行内容，不作用于对方，也不暂停弹球和配比计时。

### 3.6 核心缓冲

| 项目 | 规则 |
|---|---|
| Item ID | `DUEL_ITEM_CORE_BUFFER` |
| 效果 | 本方核心获得 1 层缓冲，使下一次砖块触底伤害减少 1。 |
| 持续时间 | 15 秒。 |
| 重复接取 | 层数不叠加；持续时间重置为 15 秒。 |
| 触发后 | 缓冲层立即消失；触底砖仍按规则从场上移除。 |
| 不触发情况 | 道具舱漏接、弹球失球、断线判负和系统异常不会消耗缓冲。 |

若同一固定模拟帧有多块砖触底，按 `column_id` 从小到大结算；核心缓冲只抵消排序后第一笔可减免的 1 点伤害，其余伤害正常结算。缓冲只能防止未来伤害，不能恢复已损失生命。

## 4. 状态、叠加与结算顺序

### 4.1 通用叠加规则

- 相同的限时倍率道具不叠加强度，只刷新持续时间。
- 次数型道具可以补充次数，但必须受各自上限约束。
- 不同道具可以同时存在，各自独立计时。
- 所有持续时间使用权威对局时间；暂停时停止，球重置和核心受击时不停。
- 进入 `Result` 状态后立即停止道具舱和所有道具计时，清除全部分裂球，并冻结最终状态供回放展示。
- 基础道具不继承到下一局、加赛或重赛。

### 4.2 单个固定模拟帧的推荐顺序

```text
读取玩家输入
→ 更新挡板位置
→ 结算道具舱接取
→ 应用本帧新获得的道具状态（含生成分裂球）
→ 更新母球与分裂球碰撞
→ 更新各砖列位置及连续补砖
→ 结算砖块触底与核心缓冲
→ 移除砖块命中次数耗尽或越界的分裂球
→ 推进道具计时并处理到期
→ 检查核心生命与胜负
```

同一帧接到的效果可以影响该帧后续的弹球、砖潮和伤害结算。这样玩家看到“已接取”的反馈后，不会在同一帧仍因旧状态受击。

### 4.3 道具系统内部数值边界

- 每种道具只维护一份明确的状态，不重复创建同类倍率或计时器。
- 挡板宽度最终倍率建议钳制在 `[0.75, 1.50]`。
- 弹球半径最终倍率建议钳制在 `[1.00, 1.25]`，且只作用于母球。
- 本方整片砖潮最终速度倍率建议钳制在 `[0.50, 1.50]`，并始终同步补砖公式。
- 核心缓冲层上限为 1，不能将减伤转化为生命恢复。
- 相位钻头使用独立的 `pierce_charges`，总上限为 5，且只作用于母球。
- 每颗分裂球 `remaining_brick_hits` 上限为 3；同半场不设分裂球数量上限，寿命仅由砖块命中次数约束。

## 5. HUD 与反馈

### 5.1 道具舱识别

每种道具必须同时使用不同图形轮廓和颜色，不能只靠颜色区分：

| 道具 | 建议轮廓 | 建议主色 | 接取短文本 |
|---|---|---|---|
| 宽幅组件 | 横向双箭头 | 青色 | `挡板扩展` |
| 扩容球体 | 同心圆 | 白蓝色 | `球体扩容` |
| 相位钻头 | 钻头/前向箭头 | 紫色 | `相位贯穿 ×3` |
| 裂变球体 | 一分为二的双圆 | 橙黄色 | `裂变球体` |
| 阻尼脉冲 | 减速波纹 | 冰蓝色 | `砖潮减速` |
| 核心缓冲 | 六边形护片 | 金色 | `核心缓冲` |

### 5.2 状态显示

- 本方挡板附近显示当前生效的短时状态图标和环形剩余时间。
- 次数型效果直接显示剩余次数，例如 `×3`。
- 分裂球在球旁显示剩余砖块命中次数，例如 `3/3`、`2/3`；母球不显示该计数。
- 核心缓冲图标贴近本方核心生命区，但不得挤压中央比赛时间。
- 对手侧显示缩小版状态图标，使竞技信息保持公开；不显示对手道具舱的接取辅助线。
- 同时存在多个效果时按“弹球 → 挡板 → 砖潮 → 核心”固定顺序排列；裂变球体计入弹球组。
- 每次接取只显示不超过 0.8 秒的短文本，不暂停操作，不遮挡弹球和危险砖。

### 5.3 到期与消耗反馈

- 限时效果结束前 1 秒，图标开始均匀闪烁，不使用全屏警告。
- 相位钻头每消耗 1 次时更新数字，并播放短促穿透反馈。
- 分裂球每命中 1 块砖时更新剩余次数；最后一次撞砖后播放短促消散，不使用失球音效。
- 核心缓冲触发时先播放护片破碎，再刷新生命；若伤害被完全抵消，生命数值不跳动。
- 道具舱漏接时在核心线处淡出，不播放与核心受击相似的音效。

## 6. 公平、随机与联网规则

- 双方共享相同的 `？` 砖位置和对应 `item_id`。
- 道具舱生成、轨迹、接取、过期、状态开始与状态结束均由权威固定帧结算。
- 分裂球的生成帧、初始方向、剩余砖块命中次数与消失事件必须可权威回放。
- 客户端不能在击碎 `？` 砖后自行抽取道具类型。
- 回放至少记录或可重建：`item_id`、来源 `(row_id, column_id)`、生成帧、接取玩家、接取帧、到期帧、分裂球生成/消耗事件。
- 断线重连必须恢复仍在场的道具舱、分裂球及剩余状态时间/次数。
- 不根据双方生命差、清砖数或领先状态修改道具类型、掉落速度和效果数值。
- 未接到道具属于可观察的操作结果，不提供自动补发或落后补偿。

## 7. 平衡红线

- 每方始终最多 1 颗母球；道具不得永久把对局改造成无次数限制的多球模式。
- 分裂球是唯一允许的临时复制体；每颗最多命中 3 次砖块，撞挡板与边界不耗次数，且不设同半场数量上限。
- 母球接取裂变球体后，自身状态不得被改写；已有分裂球被作为源球时，其剩余撞砖次数也不得被改写。
- 道具不得改变 `V_ball_base`，包括加速、减速和碰撞后增速。
- 道具不得直接扣除对方核心生命、改变对方挡板或加速对方砖潮。
- 道具不得恢复生命、提高最大生命或让核心长期无敌。
- 道具不得清除整屏、整行或无限数量砖块。
- 砖潮速度效果不得只改砖块位移而不改补砖间隔。
- 道具不能重抽或改写已经记录的逻辑行内容。
- 不因玩家漏接道具而暂停弹球、砖潮或对局时间。
- 任一道具都必须在 10 秒内自然结束，核心缓冲的等待窗口可放宽到 15 秒；分裂球以砖块命中次数耗尽为自然结束条件，可不另设秒表。

## 8. 首轮原型参数

| 参数 | 建议值 |
|---|---:|
| `？` 砖击碎掉落率 | 100% |
| 首发道具种类 | 6 |
| 道具池权重 | 各 1/6 |
| 道具洗牌袋大小 | 12 个（每种 2 个） |
| 同半场未接取道具舱上限 | 2 |
| 道具舱速度 | `0.65 × V_ball_base` |
| 宽幅组件 | 宽度 `×1.25`，8 秒 |
| 扩容球体 | 半径 `×1.15`，8 秒 |
| 相位钻头 | 3 次，最长 10 秒，最多 5 次 |
| 裂变球体 | 己方每个在场球各分裂 1 颗新球；新球各 3 次砖块命中；不设数量上限 |
| 阻尼脉冲 | 砖潮速度 `×0.70`，4 秒 |
| 核心缓冲 | 1 层，15 秒 |

这些数值是原型起点。若实际场地中平均每 20 块砖出现 1 个 `？` 砖，则道具强度应先通过持续时间和倍率调整，不应先提高 `？` 砖占比，以免同时改变基础清砖成本与画面密度。

## 9. 暂不进入首发池的道具

| 候选机制 | 暂缓原因 |
|---|---|
| 无限多球 / 无砖块次数限制的分裂球 | 破坏母球可读性与基础性能边界；有限撞砖次数的裂变球体已进入首发池。 |
| 球速提升/降低 | 破坏固定球速规则，并提高后段反应负担。 |
| 直接加血 | 削弱生命差的可读性，可能让无尽局过度延长。 |
| 全屏清除/整行爆破 | 过度替代弹道规划，且会制造大幅压力波动。 |
| 对方挡板控制 | 失败原因不再只来自本方操作和弹道选择。 |
| 向对方添加垃圾砖 | 需要独立的公共 PvP 互动规则与镜像公平验证。 |
| 单列加速/减速 | 容易造成阵型错位和认知负担，留给后续进阶道具。 |
| 自动瞄准 | 容易替代挡板落点操作，可先用纯视觉轨迹提示做独立实验。 |
| 弹球磁吸/停球 | 会改变连续碰撞和失球判定，需要独立输入方案。 |

## 10. 验收指标

1. 新玩家第一次接取后，是否能在 3 秒内说出道具的大致作用。
2. 玩家是否会为了接取道具舱做出可观察的挡板路线选择，而不是道具自动入账。
3. 道具是否提升危险局面的处理空间，但不能持续掩盖清砖效率不足。
4. 开启道具后，场面是否始终只有 1 颗可追踪母球；分裂球若存在，是否带有清晰的剩余砖块命中次数且会因撞砖耗尽而消失。
5. 扩容球体是否不会导致同一接触重复伤害、卡砖或穿墙。
6. 相位钻头是否严格按砖块接触次数消耗，并保持每块每次仅 1 点伤害。
7. 裂变球体是否对己方每个在场球各生成 1 颗新球，且所有源球状态完全不变；新球最多结算 3 次砖块命中，撞挡板与边界不耗次数。
8. 阻尼脉冲期间，砖块移动和连续补砖是否始终使用同一实际速度。
9. 同帧多砖触底时，核心缓冲的消耗顺序是否在本地、联网和回放中一致。
10. 相同种子和相同输入下，双方 `？` 砖的潜在道具与全部结算是否可确定性复现。
11. 玩家失败后，能否区分“没有清掉砖”“为了接道具漏球”和“效果使用窗口不佳”。
12. 道具是否没有显著拉长平均对局时长，尤其是阻尼脉冲、核心缓冲与裂变球体连续出现时。
13. HUD 是否在同时存在多个效果与分裂球计数时仍不遮挡弹球、危险砖和中央生命/时间信息。

## 11. 推荐实施顺序

```text
确定性 item_id 与逻辑行记录
→ 道具舱生成、下落、接取和漏接
→ 宽幅组件
→ 相位钻头
→ 阻尼脉冲
→ 核心缓冲
→ 扩容球体与连续碰撞专项验证
→ 裂变球体（每个在场球各分裂 1 颗、仅计 3 次撞砖、不设数量上限）
→ HUD、音效、回放与重连
→ 六道具等权重实战测试
```

优先实现宽幅组件，是因为它只修改挡板尺寸，最适合先验证完整的“掉落—接取—生效—到期”链路。扩容球体与裂变球体放到后段，因为它们对连续碰撞、对象生命周期和确定性模拟的风险更高。
