# GatebreakerArena

Gatebreaker Arena 是一个基于 Unity 的多人弹球攻防竞技项目。

项目当前复用 `App.AOT / App.Shared / App.HotUpdate` 三层架构，并以 HybridCLR 和 YooAssets 作为热更新与资源管线基础。

当前重点：

- 保持 Unity 工程骨架干净、可打开、可编译
- 保持清晰的 `App.AOT / App.Shared / App.HotUpdate` 分层边界
- 正式运行时资源统一通过 YooAssets 加载
- 使用项目文档维护流程记录迭代、生成提交建议和维护长期文档

## 挡板操作

手机战斗中按住屏幕左半侧向左移动，右半侧向右移动（中线归右侧）；全屏包含 HUD 与视口留白，跨中线换向，松手停止。最先按下的有效手指控制方向，释放后由最早仍按住的手指接替。技能与暂停按钮可同时响应，移动不受 UI 命中遮挡。

菜单、加载、倒计时、暂停和结算期间不接受移动；进入战斗、恢复或切回前台后需重新按下。编辑器支持鼠标左键模拟全屏按住，并保留 A/D、左右方向键；有效触摸优先于键盘及旧 UI 移动轴。普通对局与双向砖潮共用此行为，联机沿用既有输入同步时延。
